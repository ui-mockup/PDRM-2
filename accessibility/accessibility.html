Reusable accessibility panel

This page is the standalone version of the accessibility tools. Copy the accessibility folder into any website project, add one button and one script tag, and the panel works the same way it does on the JAWHAR homepage.

1. Add it to any page

<!-- wrap the content that should be affected -->
<div id="a11y-root">
  ...your header, main, footer...

  <!-- any element with data-a11y-open opens the panel -->
  <button type="button" data-a11y-open aria-label="Accessibility">♿</button>
</div>

<script src="accessibility/a11y.js"
        data-lang="ms"
        data-storage-key="mysite-a11y" defer></script>

2. Match the website's colours

:root{
  --a11y-primary:#0E1E5B;   /* header + text   */
  --a11y-primary-2:#1F3A8A; /* header gradient */
  --a11y-accent:#F8B400;    /* yellow line, active dot, focus */
  --a11y-blue:#1D4ED8;      /* icons + active border */
  --a11y-soft:#EEF3FF;      /* active tile background */
  --a11y-font:'Poppins',sans-serif;
}

3. Options

Attribute on <script>DefaultWhat it does
data-root#a11y-rootThe content the tools change. If missing, the body is wrapped automatically.
data-trigger[data-a11y-open]Selector for buttons that open the panel.
data-langmsPanel language: ms or en.
data-storage-keysite-a11yWhere settings are saved in the browser. Use a different key per website.
data-read-selectorh1,h2,h3,h4,p,liWhat “Baca halaman ini” reads aloud.
data-reader-hide—Extra selectors hidden in Reader mode, e.g. .hero,.partners.

4. Helpers

  • A11y.open(), A11y.close(), A11y.reset(), A11y.setLang('en')
  • Add data-a11y-bg to elements that use a CSS background photo so “Sembunyikan imej” and “Mod bacaan” can hide it.
  • Add data-a11y-decor to anything decorative that Reader mode should remove.

Try it on sample content

Open the panel and switch on a profile such as Disleksia or Warga emas. Every change applies to this page and is remembered in this browser.
